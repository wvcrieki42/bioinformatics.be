04 Chapter Four

Alignments

Line two sequences up to reveal what they share. Dot plots show the picture; dynamic programming — Needleman-Wunsch and Smith-Waterman — finds the optimal alignment, guaranteed.

🔵

Dot plots

A visual first look: dots where two sequences match, diagonals where they align.

🧩

Dynamic programming

Build the optimal alignment from optimal sub-alignments — fill a matrix, then trace back.

🌐

Global vs. local

Needleman-Wunsch aligns end-to-end; Smith-Waterman finds the best matching region.

Dot plot

A diagonal line of dots reveals a conserved region between two sequences.

Three moves in the matrix

Each cell is the best of: diagonal (match/mismatch), up or left (gap).

Needleman-Wunsch: fill, then trace back

Scoring matrix for aligning G A T T A with G A A T (match +1, gap −1). The bright path is the optimal global alignment.

Key takeaways

  • Dot plots give a fast visual sense of similarity before any scoring.
  • Dynamic programming guarantees the optimal alignment by reusing optimal sub-solutions.
  • Each matrix cell chooses the best of a diagonal match or a horizontal/vertical gap, then you trace back.
  • Needleman-Wunsch = global (whole length); Smith-Waterman = local (best region).
