06 Chapter Six

Phylogenetics

Reconstruct the tree of life from sequence. Trees encode shared ancestry; molecular clocks date the branches; and bootstrapping tells you how much to trust them.

🌳

Reading a tree

Tips are taxa, internal nodes are common ancestors, branch lengths can mean time or change.

⏱️

Molecular clock

If mutations accumulate steadily, sequence divergence becomes a clock for dating splits.

🎲

Bootstrap support

Resample the alignment many times; how often a branch reappears measures confidence.

A rooted phylogenetic tree

Shared branches mean shared ancestry. Numbers on nodes are bootstrap support (%).

Three ways to build a tree

Different optimality criteria, different trade-offs.

Bootstrapping

Resample columns → rebuild tree → count how often each branch recurs.

Key takeaways

  • Phylogenetic trees represent hypotheses of shared ancestry, not certainties.
  • An outgroup roots the tree and orients the direction of evolution.
  • Distance, maximum-likelihood and parsimony methods trade speed for rigour differently.
  • Bootstrap values quantify how strongly the data support each branch.
